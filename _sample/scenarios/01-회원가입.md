# 시나리오: 회원가입

## 메타 정보
- **ID**: SCN-01
- **우선순위**: P0
- **목적**: 신규 사용자가 이메일 인증을 거쳐 계정을 생성하고 즉시 로그인 가능한 상태가 되는지 검증
- **사전 조건**:
  - 회원가입 페이지에 접근 가능
  - 인증 메일 수신용 임시 메일박스 또는 테스트 도메인(`environments/{env}.md` 참조)
  - DB 가 초기화된 직후가 아니어도 무방 (TC-02 용 기존 계정만 존재하면 됨)

---

## 사용자 흐름

1. 메인 페이지 → "회원가입" 진입
2. 이메일·비밀번호·약관동의 입력 후 제출
3. 입력한 이메일로 인증 링크 수신
4. 인증 링크 클릭 → 가입 완료 페이지
5. 자동 로그인 또는 로그인 페이지로 리다이렉트

---

## 테스트 케이스

### TC-01: 정상 회원가입 (happy path)
- **입력**:
  - 이메일: `qa+signup-{timestamp}@gabia.com` (중복 회피용 timestamp suffix)
  - 비밀번호: `Qa!{timestamp}` (정책 충족)
  - 약관 전체 동의
- **조작 순서**:
  1. `{메인 URL}` 진입
  2. "회원가입" 버튼 클릭
  3. 이메일·비밀번호·비밀번호 확인 입력
  4. 필수 약관 모두 체크
  5. "가입하기" 클릭
  6. 인증 메일 수신 확인 → 인증 링크 클릭
- **기대 결과**:
  - 가입 완료 페이지 노출
  - "환영합니다" 또는 동등한 성공 메시지
  - 자동 로그인 또는 로그인 페이지 리다이렉트
- **검증 포인트**:
  - 가입 완료 후 URL 이 `/welcome` 또는 `/login` 으로 변경
  - 헤더 영역에 입력한 이메일 또는 닉네임 노출 (자동 로그인 시)
  - 콘솔 에러 없음

### TC-02: 이미 가입된 이메일로 재시도
- **입력**:
  - 이메일: `environments/{env}.md` 의 "일반 사용자" 계정 이메일 (이미 존재)
  - 비밀번호: `Qa!Existing01`
- **조작 순서**:
  1. 회원가입 페이지 진입
  2. 기존 이메일·비밀번호 입력
  3. 약관 동의 후 "가입하기" 클릭
- **기대 결과**:
  - 가입 진행 차단
  - "이미 가입된 이메일입니다" 또는 동등한 에러 메시지 노출
- **검증 포인트**:
  - 페이지 이동 없음 (URL 유지)
  - 에러 메시지가 입력 필드 근처에 명시적으로 표시
  - 인증 메일이 발송되지 않아야 함

### TC-03: 비밀번호 정책 위반
- **입력**:
  - 이메일: `qa+pwfail-{timestamp}@gabia.com`
  - 비밀번호: `123` (정책: 8자 이상 + 영문/숫자/특수문자 조합 가정)
- **조작 순서**:
  1. 회원가입 페이지 진입
  2. 이메일 + 짧은 비밀번호 입력
  3. "가입하기" 클릭 시도
- **기대 결과**:
  - 클라이언트 검증 단계에서 차단
  - 비밀번호 정책 안내 메시지 노출
- **검증 포인트**:
  - "가입하기" 버튼이 비활성화되거나, 클릭 시 에러 메시지 즉시 노출
  - 서버 요청이 발생하지 않아야 함 (네트워크 탭 확인)

### TC-04: 약관 미동의 상태로 제출
- **입력**:
  - 이메일·비밀번호 정상 입력
  - 필수 약관 중 1개 이상 미체크
- **조작 순서**:
  1. 회원가입 페이지 진입
  2. 이메일·비밀번호 입력
  3. 필수 약관 일부 체크 해제 상태로 "가입하기" 클릭
- **기대 결과**:
  - 가입 진행 차단
  - 미동의 약관 강조(빨간 테두리 또는 메시지)
- **검증 포인트**:
  - 페이지 이동 없음
  - 미체크 약관이 시각적으로 식별 가능

### TC-05: 인증 메일 재전송
- **선행 의존**: TC-01 의 가입 직후, 인증 링크 클릭 전 단계에서 진행
- **입력**: 별도 입력 없음 (TC-01 의 이메일 그대로)
- **조작 순서**:
  1. 인증 메일 발송 안내 화면에서 "메일 재전송" 클릭
  2. 60초 이내에 새 인증 메일 수신 확인
  3. 새 메일의 링크 클릭
- **기대 결과**:
  - 새 인증 메일이 수신됨
  - 새 링크 클릭 시 가입 완료 처리
- **검증 포인트**:
  - 60초 이내 메일 수신
  - 이전 인증 링크는 무효화 (만료/사용불가)
- **실패 시 결과**: TC-01 이 FAIL 이면 본 TC 는 `BLOCKED`
