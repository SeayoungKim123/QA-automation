# 시나리오: 로그인

## 메타 정보
- **ID**: SCN-02
- **우선순위**: P0
- **목적**: 등록된 사용자가 자격증명으로 인증되어 보호된 영역에 접근할 수 있는지, 그리고 잘못된 시도가 정책대로 차단되는지 검증
- **사전 조건**:
  - `environments/{env}.md` 의 "일반 사용자" 계정이 존재 (없으면 SCN-01 회원가입 후 진행)
  - 로그인 페이지 접근 가능

---

## 사용자 흐름

1. 메인 페이지 또는 보호된 페이지 접근 → 로그인 페이지로 유도
2. 이메일·비밀번호 입력 후 제출
3. 인증 성공 시 원래 의도한 페이지(또는 대시보드)로 리다이렉트
4. 인증 실패 시 에러 메시지 노출, 페이지 유지

---

## 테스트 케이스

### TC-01: 정상 로그인 (happy path)
- **입력**:
  - 이메일: `environments/{env}.md` "일반 사용자" 계정
  - 비밀번호: 동 계정의 비밀번호
- **조작 순서**:
  1. 로그인 페이지 진입
  2. 이메일·비밀번호 입력
  3. "로그인" 클릭
- **기대 결과**:
  - 대시보드 또는 메인 페이지로 리다이렉트
  - 헤더에 사용자 이메일/닉네임 노출, "로그아웃" 메뉴 활성
- **검증 포인트**:
  - URL 이 `/login` 에서 보호 영역 경로로 변경
  - 세션 쿠키 또는 인증 토큰 발급 확인
  - 콘솔 에러 없음

### TC-02: 잘못된 비밀번호
- **입력**:
  - 이메일: 정상 계정
  - 비밀번호: `Wrong!Password00`
- **조작 순서**:
  1. 로그인 페이지 진입
  2. 정상 이메일 + 잘못된 비밀번호 입력
  3. "로그인" 클릭
- **기대 결과**:
  - 인증 실패 메시지 노출
  - 페이지 이동 없음
- **검증 포인트**:
  - 에러 메시지가 "이메일 또는 비밀번호가 올바르지 않습니다" 같은 **모호한 문구**여야 함 (계정 존재 여부 노출 금지)
  - 입력 필드 비밀번호는 자동 클리어 또는 유지 정책에 따름

### TC-03: 존재하지 않는 계정
- **입력**:
  - 이메일: `noexist+{timestamp}@gabia.com`
  - 비밀번호: 임의값
- **조작 순서**:
  1. 로그인 페이지 진입
  2. 미가입 이메일 + 임의 비밀번호 입력
  3. "로그인" 클릭
- **기대 결과**:
  - 인증 실패 메시지 노출 (TC-02 와 동일 문구)
- **검증 포인트**:
  - 에러 문구가 TC-02 와 **동일**해야 함 (계정 존재 유무 enumeration 방어)
  - 응답 시간이 TC-02 와 유사해야 함 (timing attack 방어, 참고용)

### TC-04: 비밀번호 연속 실패 → 계정 잠금
- **선행 의존**: TC-02 와 동일 계정 사용
- **입력**:
  - 이메일: 정상 계정
  - 비밀번호: 잘못된 값으로 연속 N회 (정책 N 은 `specs/` 참조, 일반적으로 5회)
- **조작 순서**:
  1. 로그인 페이지에서 잘못된 비밀번호로 N회 연속 시도
  2. N+1 회째 **올바른** 비밀번호로 시도
- **기대 결과**:
  - N+1 회째도 로그인 차단
  - "계정이 잠겼습니다" 또는 정책상 메시지 노출
- **검증 포인트**:
  - 정책에 명시된 N 회 도달 시 잠금 활성화
  - 잠금 해제 안내 (관리자 문의·일정 시간 후 자동 해제 등) 노출
- **실패 시 결과**: TC-02 가 FAIL(에러 메시지 비정상 등) 이면 본 TC 는 `BLOCKED`
- **사후 정리**: 다음 시나리오에 영향 없도록 잠금 해제 (관리자 계정으로 해제 또는 별도 테스트 계정 사용 권장)

### TC-05: 로그아웃
- **선행 의존**: TC-01 PASS
- **입력**: 입력 없음
- **조작 순서**:
  1. TC-01 로그인 직후 상태에서 "로그아웃" 클릭
  2. 보호된 페이지(예: 대시보드 URL)에 직접 재접근 시도
- **기대 결과**:
  - 로그아웃 후 메인 또는 로그인 페이지로 이동
  - 보호된 페이지 직접 접근 시 로그인 페이지로 리다이렉트
- **검증 포인트**:
  - 세션 쿠키/토큰 무효화
  - 뒤로가기로 보호 페이지가 캐시 노출되지 않음

## 정책 참조
- `specs/` — 로그인 실패 횟수 / 계정 잠금 정책
- `specs/` — 세션 만료 / 자동 로그아웃 정책
- `specs/` — 에러 메시지 노출 정책 (계정 enumeration 방어)
